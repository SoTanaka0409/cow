# も〜たまらん 爽快牛キャッチャー
UFOを操作して牛をビームで捕獲し、コンボを繋いでハイスコアを目指すフル3Dアクションゲームです。
商用ゲームエンジンを使用せず、C++とDxLibを用いてチーム開発（5名）で構築しました。
## 概要 
- **ジャンル**：3Dアクション / スコアアタック
- **プラットフォーム**：PC (Windows)
- **開発環境 / 言語**：C++17 / DxLib / Effekseer
- **開発規模**：チーム制作（5名）
- **担当役割**：チームリーダー / メインプログラマー
## 技術的なアピールポイント
チーム開発を円滑に進めるためのアーキテクチャ設計と、ゲームエンジンに頼らないコアシステムの実装を主導しました。
* **チーム開発を見据えたアーキテクチャ設計**
  * `SceneManager`によるポリモーフィズムを用いたライフサイクル管理。
  * `ObjectManager`による遅延削除を採用し、更新ループ中のコレクション破壊を防止。
  * `ServiceLocator`を用いた依存分離により、クラス間の結合度を低下。
* **数学的アプローチによる自作当たり判定システム**
  * Sphere（球）とCapsule（線分＋球）の判定を独自実装。平方根計算の省略による軽量化や、OnEnter / OnTrigger / OnExit の3種のイベントを自動発火する`ColliderManager`を構築しました。
* **Stateパターンを用いたAI設計**
  * 牛の各行動（待機・移動・逃走・吸引中・消滅）を独立した状態クラスに分割し、巨大な分岐処理を排除する疎結合な設計を徹底しました。
* **堅牢なコード品質管理**
  * `const` 修飾子による状態不変性の保証と不要なメモリ複製の排除。
  * Doxygenを利用したドキュメント整備を行い、チームメンバーのコード可読性を向上。
