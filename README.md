## 💡 コンセプト・ゲーム概要

UFOを操作して地上にいる牛をビームで吸い込み捕獲する、爽快感重視のフル3Dスコアアタックアクションです。

- **リソース管理と捕獲アクション**:
  - 移動とビーム照射によるシンプルな操作系。ビーム照射中はアブダクションゲージを消費するため、無駄撃ちを避ける立ち回りが求められます。
- **コンボシステム & フィーバーモード**:
  - 途切れずに連続して牛を捕獲することでスコア倍率が上昇。特定条件で現れる金の牛を捕獲するとフィーバーモードに突入し、ゲージ無消費で一気に高得点を狙えます。
- **機体強化システム**:
  - ゲームの進行に応じてスキルを解放し、プレイスタイルに合わせたUFO性能の強化が可能です。

## 🛠 技術的なこだわり・アピールポイント

### 1. State管理によるゲーム内イベント制御と状況変化の実装
- **取り組んだ理由**:
  - 単調な作業感を出さず、ゲームの進行に応じて常に緊張感と楽しさを提供できるよう、動的に状況が変化するイベント制御を組み込みました。
- **工夫した点・実装内容**:
  - **Stateによるゲーム進行管理**:
    - ゲーム全体の進行フェーズをStateパターンで管理し、状況に応じたイベントの切り替えを一元化しました。
  - **牛の出現アルゴリズムの変化**:
    - 通常フェーズやフィーバー時、後半のラッシュ時などで出現位置や群れのパターン、レアな牛のスポーン確率などを状態ごとに動的に切り替える仕組みを構築しました。
  - **邪魔ギミックの強化・連動**:
    - 進行度やイベント発生に合わせて、プレイヤーの捕獲を妨害するギミックの挙動や出現頻度を段階的に強化し、飽きさせないゲームバランスを実現しました。

### 2. 5人チーム開発を破綻させない「共通基盤の設計」
- **取り組んだ理由**:
  - メインプログラマーとして、他メンバーが実装を進めやすく、変更に強い土台を作るために設計を整えました。
- **工夫した点・実装内容**:
  - **シーン管理（SceneManager）**:
    - シーン基底クラスを定義し、初期化・更新・描画・終了処理を一元管理。新シーン追加時に既存のコードを汚さない構造にしました。
  - **遅延削除による不正アクセス防止（ObjectManager）**:
    - オブジェクトの更新ループ中に即座に削除するとコレクションが破壊されるため、生存フラグを用いた遅延削除を採用しました。
  - **サービスロケーター（ServiceLocator）**:
    - 音声・入力・リソース管理へのアクセスを一元化し、グローバル変数の乱用を防いでクラス間の結合度を低く保ちました。

### 3. Stateパターンによる牛の自律AI
- **工夫した点・実装内容**:
  - 牛の行動（待機・移動・逃走・吸引中・消滅）を個別の状態クラスに分け、巨大なif文やswitch文を作らない疎結合な設計を徹底しました。

## 🔧 課題と問題解決

| 直面した問題 | 原因 | 解決策（アプローチ） |
| :--- | :--- | :--- |
| **イベント発生時の重複スポーンによるクラッシュ** | イベント発生時に、通常の定期スポーン処理とイベント用の大量出現処理が同じフレームで重なって走り、想定以上の生成負荷と管理配列の許容オーバーが発生していた。 | `CowManager` に出現の優先順位判定を実装。同時にステージ上に存在できる牛の上限数を厳格に管理し、上限を超える場合は通常スポーンを一時停止・破棄する制御を入れて安全に大量出現を行えるようにした。 |
| **Gitで同一クラスを複数人が編集することによる競合（コンフリクト）** | 複数人で開発を進める中で、作業範囲が重なり同じファイル・同じクラスを同時に変更してしまい、マージ時の衝突が多発した。 | チームリーダーとしてメンバーそれぞれの「その日の作業内容」を毎朝具体的に指示・割り振り、担当するファイルやクラスが被らないようにタスクを整理した。これによりコンフリクトの発生を防ぎ、円滑なプロジェクト進行を実現した。 |

## 🛡 コード品質への取り組み

- **const修飾子の徹底**:
  - メンバの値を書き換えない参照関数には `const` を徹底付与し、不意な書き換えをコンパイル段階で検知できるようにしました。
- **const参照渡しの徹底**:
  - サイズの大きい構造体や文字列は `const` 参照渡しを行い、無駄なメモリコピーの負荷を排除しました。
- **Doxygen形式のドキュメント記述**:
  - 公開メソッドに引数・戻り値・事前条件を明記し、チームメンバーが他人のコードを読む時間を短縮させました。

## 🕹 操作方法

### 通常操作
| キー / 入力 | アクション |
| :--- | :--- |
| `W` / `A` / `S` / `D` | UFOの前後左右への移動 |
| `マウス左クリック`（長押し） | ビーム照射（吸い込み） |
| `Enter` | 決定・UI操作 |

### デバッグ用操作（フリーカメラ）
| キー / 入力 | アクション |
| :--- | :--- |
| `W` / `A` / `S` / `D` | カメラの空間内移動（空間内を自由に移動） |
| `マウス移動` | 視点操作（見回す） |
